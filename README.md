# Devansh Bhardwaj - Portfolio

Welcome to my personal portfolio! This is a unique, "vibe-coded" browser-themed portfolio built using pure HTML, CSS, and JavaScript.

## Features
- 🌐 **Browser UI**: A custom desktop browser experience built from scratch.
- 🎨 **Glassmorphism**: Modern frosted glass aesthetics.
- 🖼️ **Dynamic Wallpapers**: Change the background wallpaper dynamically.
- 🤖 **3D Stylized Avatar**: Custom 3D avatar with hover tilt effects.
- 📱 **Fully Responsive**: Optimized for desktop, tablet, and mobile viewing.
- 🔍 **Intelligent Search**: Use the URL bar to search and navigate instantly.

## Tech Stack
- **HTML5**: Semantic structure.
- **CSS3**: Custom design system, CSS variables, flexbox/grid layouts, animations, and media queries (No external libraries like Tailwind or Bootstrap).
- **Vanilla JavaScript**: DOM manipulation, particle system, and state management without React or Vue.

## How to Run Locally
1. Clone this repository.
2. Open `index.html` in any modern web browser.
3. (Optional) Run a local server:
   ```bash
   python -m http.server 8080
   ```
   Then visit `http://localhost:8080` in your browser.
